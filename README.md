# DevNotes

DevNotes é uma aplicação web de gerenciamento de notas desenvolvida com HTML, CSS e JavaScript.

O projeto permite criar, editar, excluir e fixar notas, além de oferecer busca, exportação para CSV e armazenamento dos dados utilizando LocalStorage.

O layout é responsivo e foi desenvolvido com foco na prática de manipulação do DOM, eventos e persistência de dados no navegador.

## Funcionalidades

- Criar, editar e excluir notas
- Fixar notas e mantê-las no topo
- Buscar notas
- Salvar notas no LocalStorage
- Exportar notas para CSV
- Interface responsiva

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
